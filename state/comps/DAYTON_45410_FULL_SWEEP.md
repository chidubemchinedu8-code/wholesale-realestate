$135.09/sf and that is the number used. **The cost of that choice is real:** a 2,400 sf
subject is being valued at $135/sf off a band whose own large-house comps say $69–$93.

## Scope and method honesty

- **No filter.** All 78 live listings pulled and recorded, including land, commercial,
  multifamily and the turnkey retail-ready stock. 37 rejects are in the roster with a
  named reason.
- **ARV band: NONE.** `ARV BAND: NONE — error UNMEASURED` for every 45410 row. There is
  no backtest for this ZIP and the Cuyahoga ±40% band is **not** importable (D-29).
- **D-37 applied differently here, not ignored.** 45410 has no coordinates (geocoder
  unreachable), so instead of giving every property one shared lat/lon and printing a
  vacuous "within 1.5 mi" pass, these runs used the engine's new **`--zip-wide`** mode:
  the pool is every sale in the ZIP that survives the hood/bed/sqft gates, and the
  report says **"ZIP-WIDE (no radius)"** everywhere a distance would have gone. Radius is
  `None`, and the radius check now says it was never applied. **A neighbourhood-level
  (Walnut Hills / South Park / Belmont / Linden Heights) comp set would be tighter than
  what is reported here — and is not what this file claims.**
- **Estimates, not appraisals.** Nothing here is an offer. No buyer is secured.
